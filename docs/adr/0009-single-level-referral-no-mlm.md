# Referral is strictly single-level — no MLM, no network override

## Context

Because any Member can become an **Agent**, a referred Member (B) can themselves level up
and become an Agent. This raises the question: does the Agent who brought B (A) earn
anything on B's *own* referral sales? Answering "yes" would turn the program into a
multi-level marketing / pyramid structure — legally radioactive in FluoFit's jurisdictions
(Dubai + Serbia) and toxic to a brand built on community trust.

## Decision

**Strictly single-level.** An Agent earns commission **only on Members they personally
referred** — never an override or cut on the sales of other agents beneath them, and there
is no notion of a downline or network. When B becomes an Agent, B is fully independent; A
has no claim on B's referral activity.

(A keeps earning commission on **B's own personal Subscription** while B stays subscribed —
that is a normal referred-Member commission, not a network override.)

## Consequences

- The program stays a clean, lawful single-tier affiliate model.
- No recruitment-of-recruiters incentive — Agents are rewarded for selling product, not for
  signing up other agents.
- Removes a whole class of pyramid-fraud and regulatory exposure by construction.
